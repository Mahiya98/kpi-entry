Entries are kept in this browser (localStorage) and pushed to your Google Sheet when you press Save to Sheet or Submit Data.
Connect to Google Sheet — 4 steps
  1. Open your Google Sheet → Extensions → Apps Script, delete any code and paste the script below.
  2. Click Deploy → New deployment → type Web app → Execute as Me, Access: Anyone → Deploy, then copy the /exec URL.
  3. Paste that URL above, press Save URL, then Test connection. Use Save to Sheet any time to keep a draft copy of the selected month + SBU.
  4. When the month is complete, press ✔ Submit Data — the rows are upserted to the sheet with a Submitted At timestamp and the month is locked (use Reopen if you must edit again).
The script creates two tabs automatically: KPI Data (month-year entries) and KPI Master. Re-upload a new version of the script if you change it (Deploy → Manage deployments → Edit).
